Questions

Good to know.

What is tallow?

Tallow is a rendered form of animal fat. In this formula it provides the rich, emollient base of the moisturiser.

How should I use it?

Warm a small amount between clean fingertips and massage onto slightly damp skin. Start with less than you think you need.

Is it scented?

This concept product is unscented. If you add essential oils or fragrance to a final formula, update the ingredient and allergen information accordingly.

Can I use it on my face?

Many people use rich balms on the face, but skin can react differently. Patch test first and discontinue use if irritation occurs.
